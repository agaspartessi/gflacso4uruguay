# gflacso4uruguay

Theme hijo de Boost para FLACSO Uruguay. Rama `moodle-5.3`.

Versión **2.0.0-beta6** (`2026101703`), requiere Moodle y Boost **5.3**.
Actualiza cajones, navegación, login y carga SCSS, conservando la paleta,
imágenes, footer institucional y estilos de contenidos de Uruguay.

Pendiente de validación con los cursos, plugins y ajustes reales del campus.
Ver [cambios, pruebas e instalación](docs/MOODLE_5_MIGRATION.md).
